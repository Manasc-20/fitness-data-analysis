# Fitness Lifestyle Analysis Dashboard

A data analytics project that explores the relationship between lifestyle habits and workout consistency using survey data collected from 65 participants. The project demonstrates the complete analytics workflow—from data collection and cleaning to exploratory data analysis using Python (Pandas) and an interactive Power BI dashboard.

---

## 📋 Project Overview

This project analyzes how factors such as sleep duration, diet, age group, and workout habits influence workout consistency. Survey responses were collected through Google Forms, cleaned in Excel, analyzed using Python, and visualized in Power BI to uncover meaningful trends and actionable insights.

---

## 🎯 Objectives

- Analyze workout consistency across different age groups
- Explore the relationship between sleep duration and workout frequency
- Understand how diet influences exercise habits
- Identify common reasons participants skip workouts
- Build an interactive dashboard for data-driven insights

---

- **Microsoft Excel** – Data cleaning and preprocessing

## 🔍 Key Insights

- Most participants reported working out **5+ days per week**.
- Participants sleeping **7+ hours** generally showed greater workout consistency.
- A **Mixed Diet** was the most common dietary pattern among respondents.
- **Feeling tired** and **lack of time** were common reasons for skipping workouts.
- The majority of responses came from the **16–22 age group**, reflecting the survey audience.
